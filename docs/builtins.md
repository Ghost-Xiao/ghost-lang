# 内置函数说明

Ghost Language 提供了以下内置函数，用于常见的操作和功能：

## print 函数

### 功能描述
打印一个或多个参数到标准输出，参数之间用空格分隔，不自动换行。

### 参数列表
| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| 参数1, 参数2, ... | 任意类型 | 无 | 要打印的值，可以是多个参数 |

### 返回值
| 类型 | 说明 |
|------|------|
| null | 函数执行后返回空值 |

### 使用示例
```ghost
print("Hello", "World"); // 输出: Hello World
print(1, 2, 3); // 输出: 1 2 3
```

### 注意事项
- 函数支持可变参数，可以传入任意数量的参数
- 所有参数会被转换为字符串后打印
- 不会自动添加换行符

## println 函数

### 功能描述
打印一个或多个参数到标准输出，参数之间用空格分隔，并在末尾添加换行符。

### 参数列表
| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| 参数1, 参数2, ... | 任意类型 | 无 | 要打印的值，可以是多个参数 |

### 返回值
| 类型 | 说明 |
|------|------|
| null | 函数执行后返回空值 |

### 使用示例
```ghost
println("Hello, World!"); // 输出: Hello, World!
println(1, 2, 3); // 输出: 1 2 3
```

### 注意事项
- 函数支持可变参数，可以传入任意数量的参数
- 所有参数会被转换为字符串后打印
- 会自动添加换行符

## len 函数

### 功能描述
返回字符串的长度（字符数）或列表的长度（元素个数）。

### 参数列表
| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| a | 字符串或列表 | 无 | 要获取长度的值 |

### 返回值
| 类型 | 说明 |
|------|------|
| 整数 | 表示字符串的字符数或列表的元素个数 |

### 使用示例
```ghost
len("Hello"); // 返回: 5
len([1, 2, 3, 4, 5]); // 返回: 5
```

### 注意事项
- 参数必须是字符串或列表类型
- 对于字符串，返回的是字符数（使用 UTF-8 编码计算）
- 对于列表，返回的是元素个数

### 异常处理
如果参数不是字符串或列表类型，函数会抛出类型错误：
```ghost
len(123); // 抛出类型错误: len() argument must be a sequence or collection.
```

## power 函数

### 功能描述
计算一个数的幂，返回底数的指数次方。

### 参数列表
| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| a | 整数或浮点数 | 无 | 底数 |
| n | 整数或浮点数 | 无 | 指数 |

### 返回值
| 类型 | 说明 |
|------|------|
| 浮点数 | 计算结果，底数的指数次方 |

### 使用示例
```ghost
power(2, 3); // 返回: 8
power(4, 0.5); // 返回: 2
power(2, -1); // 返回: 0.5
```

### 注意事项
- 底数和指数都可以是整数或浮点数
- 结果始终以浮点数形式返回
- 支持负指数计算

### 异常处理
如果参数不是整数或浮点数类型，函数会抛出类型错误：
```ghost
power("2", 3); // 抛出类型错误
```
