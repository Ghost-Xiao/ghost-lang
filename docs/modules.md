# 内置模块说明

Ghost Language 提供了以下内置模块，用于常见的功能。

## 模块导入方式

使用 `import` 语句导入内置模块（注意模块名是字符串）：

```ghost
import "math";
import "fmt";
import "io";
```

导入的模块可以通过成员访问表达式访问其成员：
```ghost
import "math";
math.PI;
math.sqrt(4);
```

## fmt 模块

格式化输出模块，提供字符串格式化和打印功能。

### 导入方式
```ghost
import "fmt";
```

### sprintf 函数

#### 功能描述
根据格式化字符串格式化参数，返回格式化后的字符串。

#### 参数列表
| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| format | 字符串 | 无 | 格式化字符串 |
| 参数1, 参数2, ... | 任意类型 | 无 | 格式化参数，可以是多个 |

#### 返回值
| 类型 | 说明 |
|------|------|
| 字符串 | 格式化后的字符串 |

#### 使用示例
```ghost
import "fmt";
fmt.sprintf("Hello, %s!", "World"); // 返回: "Hello, World!"
fmt.sprintf("Number: %d", 42); // 返回: "Number: 42"
fmt.sprintf("Float: %f", 3.14); // 返回: "Float: 3.140000"
fmt.sprintf("Bool: %t", true); // 返回: "Bool: true"
fmt.sprintf("Binary: %b", 42); // 返回: "Binary: 101010"
fmt.sprintf("Hex: %x", 42); // 返回: "Hex: 2a"
```

#### 格式化说明符
| 说明符 | 说明 |
|--------|------|
| %v | 默认格式，输出值的字符串表示 |
| %d | 整数格式 |
| %f | 浮点数格式 |
| %s | 字符串格式 |
| %t | 布尔值格式 |
| %b | 二进制格式 |
| %x | 十六进制格式 |
| %% | 输出百分号 |

### floor 函数

#### 功能描述
向下取整，返回小于或等于给定数的最大整数或保留指定小数位数。

#### 参数列表
| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| x | 整数或浮点数 | 无 | 要取整的数 |
| decimalPlaces | 整数 | 0 | 保留的小数位数（可选） |

#### 返回值
| 类型 | 说明 |
|------|------|
| 整数或浮点数 | 如果 decimalPlaces 为 0，返回整数；否则返回浮点数 |

#### 使用示例
```ghost
import "math";
math.floor(3.14); // 返回: 3
math.floor(-3.14); // 返回: -4
math.floor(3.14159, 2); // 返回: 3.14
math.floor(3.14159, 3); // 返回: 3.141
```

#### 注意事项
- 当 decimalPlaces 为 0 或未提供时，返回整数
- 当 decimalPlaces 大于 0 时，返回浮点数，保留指定小数位数
