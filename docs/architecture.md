# 项目架构

Ghost Language 项目的架构如下：

```
main.go → cli包 → 词法分析器(lexer)
               → 语法分析器(parser) → AST抽象语法树
               → 解释执行器(evaluator) → 运行时对象(object)
                                    → 执行环境(frame)
               → REPL交互模块
```

项目结构说明：
- **main.go**: 程序入口点，负责解析命令行参数并启动相应的功能模块。
- **cli包**: 命令行接口模块，处理用户输入的命令和参数。
- **词法分析器(lexer)**: 将源代码转换为词法单元(tokens)。
- **语法分析器(parser)**: 将词法单元解析为抽象语法树(AST)。
- **AST抽象语法树**: 表示源代码的结构化形式，是后续解释执行的基础。
- **解释执行器(evaluator)**: 执行抽象语法树表示的代码。
- **运行时对象(object)**: 表示程序运行时的数据类型和值。
- **执行环境(frame)**: 维护变量作用域和执行上下文。
- **REPL交互模块**: 提供交互式命令行界面，允许用户逐行输入和执行代码。
